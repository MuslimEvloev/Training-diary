# 🏋️ Training Diary

[🌐 Посмотреть демо](https://muslimevloev.github.io/Training-diary/)

---

## 🧠 О проекте

**Training Diary** — учебный проект на **JavaScript**,  
где я практиковал **подключение API карт** для отображения локаций тренировок.  
Проект демонстрирует работу с внешними сервисами, динамическое обновление данных и интерактивный интерфейс.

---

## 🧩 Используемые технологии
| Технология | Роль |
|-------------|------|
| 🧱 HTML5 | структура интерфейса |
| 🎨 CSS3 | стилизация и оформление |
| ⚙️ JavaScript | логика приложения и работа с API |
| 🗺️ API карт | отображение локаций тренировок на карте |

---

## 🎯 Функционал
- Отображение тренировочных локаций на карте  
- Динамическое обновление данных через JavaScript  
- Интерактивный интерфейс с кликабельными элементами  
- Простая визуализация тренировочного прогресса
